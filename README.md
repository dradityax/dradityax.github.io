Personal site of Aditya X — MBBS Student, builder.

Live site: https://dradityax.pages.dev/

## What is this

A static personal homepage, built in plain HTML, CSS and JavaScript. No framework, no backend in this repo.

A scroll-vision homepage, with projects and writing growing around it.

## Inside

- `/` — homepage (scroll vision)
- `/project-1/` — Project One, a Bihar NEET / UGMAC counselling platform (landing, converter, form practice, signup, dashboard)
- `/x-moscot/` — the X mascot
- `/assets/` — images and site assets

The `demo-*` and `try-*` folders are experiments, not part of the main site.

## How it is hosted

- Source: this repo, branch `main`
- Live via Cloudflare Pages at dradityax.pages.dev — auto-deploys on push to `main`
- Mirror via GitHub Pages at dradityax.github.io
- Mirror: dradityax.is-a.dev points to dradityax.pages.dev

## Building

No build step. Edit the HTML, CSS and JavaScript, push to `main`, and Cloudflare rebuilds.
